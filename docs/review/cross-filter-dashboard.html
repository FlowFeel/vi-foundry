Cross-Filtered Simulation Dashboard

How it works: Brush on the scatter plot (Chart A) to select seeds by k₁/k₂ ratio. All other charts update in real time — bars dim, trajectories highlight, R² dots react.

Test-informed: Specs written first in Jasmine BDD style (test/d3-dashboard.spec.js), implementation in docs/review/js/cross-filter.js. Open the test runner to verify.
